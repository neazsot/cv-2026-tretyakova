# Лабораторная 2. Классическая обработка

**Задача.** Разобраться, как работать с картинками (цвет, свет, шум) и попробовать выделить животное на фото без нейросетей, используя только пороги и морфологию.

**Как запустить.** Делала в Google Colab. Для запуска нужно открыть `starter.ipynb` с GitHub, сохранить копию на свой Диск, в первой ячейке выставить `VARIANT = 20` и нажать «Выполнить всё».

**Данные.** Вариант 20. Попались породы: Ragdoll, Sphynx, american_bulldog и boxer. Шум для нашего варианта из `NOISE_PLAN` — смешанный (`mix`), с параметрами `sigma=25` и `amount=0.05`.

**Результаты.**
Главные цифры, которые у меня получились:
| Метрика | Значение |
| :--- | :--- |
| Лучший фильтр от шума | `median7` |
| PSNR у median7 | 27.88 |
| SSIM у median7 | 0.68 |
| Лучший канал для маски | `gray` (серый) |
| Итоговая средняя IoU | 0.45 |

**Выводы.**
1. Когда я сравнивал фильтры на нашем шуме, лучшим оказался `median7` (у него SSIM 0.68 и работает он быстро, около 27 мс). Победитель по PSNR — `bilateral` (SSIM 0.72), но он очень медленный и  видно, что он замыливает шерсть, поэтому я выбрал медиану.
2. Сильнее всего цвета испортил метод `equalizeHist` по отдельным каналам RGB (сдвиг 17.41). Это потому, что он выравнивает каждый канал отдельно, и цвета съезжают. А вот CLAHE по каналу L сработал лучше всего, почти не тронув цвета (сдвиг всего 0.39).
3. Если посмотреть на яркость, то фото в датасете очень разные (от 31 до 213). Самая тёмная порода — сфинксы. 
4. В выделении животного самый большой прирост точности дала заливка дыр и взятие самой большой компоненты (без этого маска разваливалась на куски). А морфология на идеальных фото почти ничего не меняла.
5. Лучше всего сработал обычный серый канал (IoU 0.45). Хуже всего метод работает на сфинксах (IoU 0.439), потому что у них нет шерсти, и их кожа по цвету сливается с фоном. Из-за этого порог Оцу не может их нормально отделить.
